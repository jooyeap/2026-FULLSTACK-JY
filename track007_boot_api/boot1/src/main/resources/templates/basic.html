1. 텍스트 출력 -> th:text

html 태그 안의 내용을 서버에서 보낸 값으로 교체
th:text="${msg}"
th:text="${nums}"

2. 조건문 -> th:if 

특정 조건
th:if="${10>3}" 태그 벨류값 = 10 은 3 보다 크다
th:if="${10<3}" 태그 벨류값 = 10 은 3 보다 작다

10 은 3 보다 크다

10 은 3 보다 작다

$ 변수
# 타임리프에서 제공하는 값 - 유틸리티 객체식
th:if="${#lists.size(nums) > 3}" 태그 벨류값 = 데이터가 3개 이상

데이터가 3개 이상

3. 반복문 -> th:each 

$ 변수
# 타임리프에서 제공하는 값 - 유틸리티 객체식
